# rsa-franklin-reiter — 题解

> rsa / 中等 / 300 分 / 考点: Franklin-Reiter 相关消息攻击 (多项式 gcd)

## 漏洞点
e = 3 且无填充时，RSA 加密是模 n 上的多项式求值 x ↦ x³。已知两条
仅差 1 的消息 m、m+1 及其密文 c1、c2，则 x³-c1 与 (x+1)³-c2 在
Z_n[x] 中有公共因式 (x - m)。对这两个多项式跑欧几里得 gcd，得到
的一次因式直接给出 m——相关性就是可利用性。

## 利用思路
1. 读附件中的 n, e, c1, c2（m2 = m1 + 1）。
2. 构造 f1(x) = x³ - c1，f2(x) = (x+1)³ - c2（系数列表低次在前）。
3. g = poly_gcd_modn(f1, f2, n) 应为一次多项式 [a0, a1]（首一后 a1=1），
   其根 m1 = -a0·a1^-1 mod n。
4. 若某步首项系数与 n 不互素，poly_gcd_modn 会顺手返回 n 的真因子
   （意外收获）：此时直接分解 n 常规解密。
5. long_to_bytes(m1) 即 flag。

## 关键代码
g, fac = ctfk.poly_gcd_modn([(-c1) % n, 0, 0, 1],
                            [(1 - c2) % n, 3, 3, 1], n)
m1 = (-g[0] * ctfk.modinv(g[1], n)) % n   # 一次式的根

## 防御建议
- 使用 RSA-OAEP：填充使两条消息的明文整数彼此独立，多项式关系消失。
- 避免对「语义相关」的数据直接做确定性加密（计数器、自增 ID 等）。
- e=3 时应格外审慎，常规部署选 e=65537 并强制填充。
