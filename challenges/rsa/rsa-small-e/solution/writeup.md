# rsa-small-e — 题解

> rsa / 入门 / 100 分 / 考点: 小指数无填充 (直接开 e 次方根)

## 漏洞点
e = 3 且不使用任何填充。消息很短，m^3 远小于模数 n，因此
c = m^3 mod n 中的「mod n」根本没有生效——密文就是明文的立方。
在整数上开立方即可无损恢复 m，RSA 退化成了一个纯算术游戏。

## 利用思路
1. 读附件中的 n, e, c（十六进制）。
2. 直接计算整数立方根：m = iroot(c, 3)。
3. 校验 m^3 == c（确认确实没有回绕），转回字节即得 flag。

## 关键代码
m = ctfk.iroot(c, 3)
assert m ** 3 == c          # c 在整数意义下就是 m^3
print(long_to_bytes(m).decode())

## 防御建议
- 加密必须使用随机化填充（RSA-OAEP），保证每次加密的明文整数都接近 n。
- 小指数 (e=3) 只有在配合填充时才安全；否则直接被开方。
- 上线前检查典型误用：m^e < n 的消息一律拒绝加密。
