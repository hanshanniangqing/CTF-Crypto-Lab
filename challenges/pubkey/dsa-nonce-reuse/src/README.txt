DSA 随机数重用 —— 支付网关签名泄露
================================================================

风控系统导出的两条转账签名, 经审计发现它们使用了**同一个随机数 k**
(两条签名的 r 完全相同即是证据)。私钥 x 直接是本次挑战的答案
(x 的字节编码即 flag)。

文件格式 (所有数字均为十进制):
  params.json : {"p", "q", "g", "y"}
                y = g^x mod p 是公钥; q 是 256-bit 素数, p = 2*q*t + 1
  sigs.json   : [{"msg", "h", "r", "s"}, ...]
                h = sha256(msg) 的 32 字节整数 mod q
                r = (g^k mod p) mod q,  s = k^-1 * (h + x*r) mod q
